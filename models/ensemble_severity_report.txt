--- Ensemble Voting Logic ---

  For each model:
    score[predicted_severity] += weight x confidence        (hard vote)
    score[severity_s]         += weight x 0.25 x prob[s]   (soft vote)

  → Normalize scores → pick severity with highest score

  Example:
    BERT    → CRITICAL (conf=0.94)  weight=1.00
    XGBoost → CRITICAL (conf=0.88)  weight=0.85

    score[CRITICAL] = 1.00x0.94 + 0.85x0.88 + soft votes = 1.69  ← winner
    score[HIGH]     = soft votes only                      = 0.08

    → Ensemble output: CRITICAL (confidence=0.95)
